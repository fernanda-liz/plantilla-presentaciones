PLANTILLA DE PRESENTACIONES · DEMO DE PATRONES

Todo lo que esta plantilla sabe hacer

Un deck de referencia, no una presentación real: cada diapositiva muestra un patrón distinto (animación, diagramación, jerarquía de información) que después puedes copiar a un deck de verdad. Para reskinear, cambia solo las variables de color al principio de styles.css.

Nota

Portada: fondo animado ambiental + entrada escalonada de los 3 elementos de texto.

Patrón · jerarquía de información

Eyebrow → título → cuerpo → bloques numerados

El texto de apoyo va debajo del título, nunca al revés — el ojo lee en ese orden. Para reglas o pasos, usa bloques numerados en vez de una lista plana: cada uno separa "qué entra", "qué sale" y la explicación, así el lector escanea antes de leer completo.

1 — separar entra/sale

entra un dato o una decisión

sale el resultado, explícito

Se lee en dos segundos sin necesidad del párrafo completo.

2 — código como evidencia

Cuando el punto es técnico, mostrar una línea real vale más que describirlo en prosa.

Patrón · tarjetas comparativas

Tarjetas con color de borde por categoría

Cada tarjeta entra por separado (no el bloque completo) — útil para comparar 3-4 opciones, fuentes o decisiones sin una tabla pesada. El color del borde izquierdo codifica la categoría sin necesitar leyenda aparte.

Neutra

Borde azul

Uso por defecto — información sin connotación positiva/negativa.

Positiva

Borde verde

Lo que funcionó, lo confirmado, lo que se decidió sí hacer.

Riesgo

Borde rojo

Lo que falló, una advertencia, algo que se decidió NO hacer.

Patrón · diagrama de arquitectura (SVG animado)

Cajas que aparecen por columna, flechas que se dibujan

Las cajas y textos usan clase .d-caja/.d-cap (aparecen en cascada); las líneas usan .d-flecha (se "dibujan" con stroke-dashoffset). Ver main.js → prepararTurnos().

Patrón · ciclo de trabajo (loop-back)

Cuando el proceso se repite, no es un flujo lineal

La vuelta usa un <path> con pathLength="100" — así el mismo dasharray de la animación sirve para cualquier largo real de línea, sin recalcular a mano.

Patrón · ranking / barras normalizadas

Comparar magnitudes de un vistazo

Cada barra crece al entrar la diapositiva (no de golpe) — ayuda a que el ojo siga el orden correcto en vez de leer todo el gráfico a la vez.

Patrón · contraste en dos columnas

Antes / después, o código / resultado

Antes

// sin regla explícita
if (x) { y = 0; }

Después

// la ausencia se marca, no se inventa
if (x === null) { y = "sin dato"; }

Sirve igual para código, para una foto de antes/después, o para dos citas bibliográficas que se contradicen.

Patrón · red de nodos (mapa de conceptos)

Cuando la idea es una red, no una lista

El nodo central crece y "respira" (pulso sutil, infinito) para marcar la idea que organiza a las demás — útil para mapas de referentes, marcos teóricos o "todo se conecta con X".

Patrón · grilla de íconos con celda destacada

Seis ideas, una de ellas es la más importante

Ajustable

Una idea clara

Lo que el lector se lleva si solo mira esta celda.

Con evidencia

Un dato o una línea de código, no una promesa.

La celda central manda

Ocupa más espacio y usa el color de acento — el ojo sabe cuál mirar primero sin que haga falta una flecha.

Consistente

Mismo tamaño de ícono, mismo ritmo de texto en las 6 celdas.

Para tu audiencia

Seis celdas es el máximo antes de que se sienta una lista, no un mapa.

Patrón · línea de tiempo

Cuatro fases, una sola línea

El círculo crece en cada hito — comunica avance sin necesitar una barra de progreso aparte.

Utilidades incluidas

Descargar como PDF

Botón abajo a la izquierda (o tecla P). Abre el diálogo de impresión del navegador — "Guardar como PDF" produce una página por diapositiva, sin la UI de control.

Vista previa 4:3

Botón arriba a la derecha. Simula un proyector antiguo cargando el mismo deck en un iframe a 1024×768 real — no es un zoom aproximado.
